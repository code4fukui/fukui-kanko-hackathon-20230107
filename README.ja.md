# fukui-kanko-hackathon-20230107

このリポジトリは、2023年1月7日に開催されたシビックテック入門＆アイデアソンの資料をアーカイブしたものです。本イベントは高校生および高専生を対象とし、データ分析を通じて福井県の観光体験を向上させることをテーマに開催されました。学生チームは、東尋坊でのQRコードを活用した情報提供システムなど、地元の観光スポットに向けたソリューションを発表しました。

## ライブデモ

イベントの録画、写真、資料は、GitHub Pagesでホストされている静的なWebページで公開されています。

- **[イベントアーカイブページ](https://code4fukui.github.io/fukui-kanko-hackathon-20230107/)**
- [元のイベント告知（Peatix）](https://fukuidx1.peatix.com/)

## リポジトリの内容

`index.html` ファイルは、以下のメディアを折りたたみ可能なセクションでまとめたシンプルなシングルページのアーカイブとして機能します。

- **チームプレゼンテーション:** 各チームの最終プレゼンテーションの動画（`teamA.mp4`、`teamB.mp4` など）。
- **「キッズセーフ」ワークショップ:** ワークショップでの活動写真と短い動画（`kidssafe/` ディレクトリ内）。
- **360°会場写真:** A-Frameを利用したインタラクティブな会場の360°パノラマ写真。ビューワーは `group-photo/index.html` です。
- **集合写真:** 参加チームごとの写真と全体の集合写真（`group-photo/` ディレクトリ内）。

## 開発

アーカイブページをローカルで表示するには、Webブラウザで `index.html` を開いてください。

### 動画のエンコード

元の動画ファイルは、FFmpegを使用してWeb向けのMP4形式（960x540）に変換されています。以下のコマンドを使用すると、2分間の動画を約10MBに圧縮できます。

```sh
ffmpeg -i input.MOV -vf scale=-1:540 output.mp4
```
